# Stock Price Fetcher & Analyzer

A beginner-friendly Python project that fetches historical stock market data using yfinance and performs basic financial analysis and visualization.

## Features

- Fetch historical stock prices
- User-defined ticker and date range
- 20-day, 50-day and 200-day moving averages
- Total return calculation
- Daily returns
- Daily volatility
- Maximum drawdown
- Average trading volume
- Basic short-term trend analysis
- Stock price visualization
- Trading volume visualization
- Daily return visualization

## Technologies

- Python
- yfinance
- Pandas
- Matplotlib
